# Contributing to AeroStack2

## Contributions to this fork

The [aerostack2-jazzy fork](https://github.com/myamazum/aerostack2-jazzy) is maintained
by [myamazum](https://github.com/myamazum). Its focus is running Aerostack2 with
ROS 2 Jazzy through Pixi / RoboStack on Ubuntu 22.04 and 24.04 and distributing
those changes as a patch against an identified revision of upstream `main`.
Local build and regression verification currently covers Ubuntu 22.04.5;
Ubuntu 24.04 verification reports are welcome.

Please submit fork-specific fixes and test reports to this repository. Include
the upstream base commit, Ubuntu and Pixi versions, and the commands and results
needed to reproduce the issue. See the [setup notes](docs/jazzy/README.md) for the
existing regression test procedure. When changing the fork, keep its consolidated
patch and verification notes consistent with the source.

Fork-specific authorship is recorded in the [README credits](README.md#credits)
and Git commit history. Preserve upstream attribution and license notices, and
describe the scope of each contributor's changes. Upstream citation information
continues to credit the original Aerostack2 authors.

Original contributions to this fork use the project's [BSD-3-Clause license](LICENSE).
When redistributing source, retain the existing copyright notices, license
conditions, and disclaimer. When redistributing binaries, reproduce those notices,
conditions, and disclaimer in the accompanying documentation or other materials.
Do not use upstream copyright holders' or contributors' names to endorse or promote
derived products without their prior written permission. Third-party code and
dependencies remain subject to their own licenses; retain their applicable notices.

## Contributions to upstream Aerostack2

Thanks for getting involved! Information on contributing can be found at [https://aerostack2.github.io/contributing](https://aerostack2.github.io/contributing)

For changes intended for upstream, follow those guidelines and submit a pull
request to [aerostack2/aerostack2](https://github.com/aerostack2/aerostack2).
Upstream maintainers decide how contributions are merged and credited there.
